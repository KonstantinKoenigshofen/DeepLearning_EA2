# DeepLearning_EA1
Github-Repository für die Einsendeaufgabe 2 im Modul Deep Learning. Die Aufgabe war es, einen Datensatz mit einem verauschten Zwilling zu erstellen
und anhand von diesen zwei Modelle zu trainieren. Eines sollte dabei möglichst gut generalisieren, während das andere overfitten sollte. Das ganze sollte anschaulich auf einer 
Webseite dargestellt werden: <https://konstantinkoenigshofen.github.io/DeepLearning_EA2/>
